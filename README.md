# 🎧 Ultimate Ears Clone

A modern and responsive **Ultimate Ears website clone** built using **HTML and CSS**.  
This project recreates a premium audio brand website with clean UI, structured layouts, and multiple pages.

---

## 🚀 Live Demo

🔗 https://mannpatel108585-ultimate-ears-clone.netlify.app/

---

## 📌 Project Overview

This project is a **frontend clone of the Ultimate Ears website**, created to practice:

- 🎧 Audio product UI design
- 🎨 Clean and modern styling
- 📱 Responsive layouts
- 🧭 Multi-page navigation
- 🧩 Structured UI development

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- VS Code

## ⚙️ How to Run the Project

1. Clone the repository:
```
git clone https://github.com/mann2007-ptl/ultimate-ears-diwali-assgn.git
```

2. Open the folder:
```
cd ultimate-ears-diwali-assgn
```

3. Open `index.html` in browser or use Live Server.
